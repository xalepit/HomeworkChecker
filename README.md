# HomeworkChecker


HomeworkChecker是一款面向同济大学 高级语言程序设计 和 面向对象程序设计 课程作业场景的交互式检查系统，目标是把原本依赖命令行、批处理脚本和人工手敲参数核对的复杂检查流程，重构为低门槛、可视化的桌面工作流

## 当前注意事项

- 测试数据中的空行会被保留，并作为被测程序标准输入的一部分；这与原版 `get_input_data.exe` 会忽略空行的行为不同。
- 当前仅面向使用标准输入、标准输出完成测试的程序，暂不支持依赖 `_getch()`、光标控制或控制台键盘交互的作业。
- 空行只表示标准输入中的换行，不会被转换为控制台 Enter 按键，因此不能用于驱动 `_getch()` 等直接读取控制台键盘的函数。
- 外部程序超时会作为独立执行结果返回；单次运行时限可在通用设置中配置为 3–10 秒，默认 5 秒。

## 命令行参数

可在每个测试用例的实际输入之前使用 `# @args:` 指定参数；Demo 与学生程序始终使用同一组参数：

```text
[case-1]
# @args: --parameter1=123 --name="value with spaces"
standard input

[case-2]
# @args: --parameter1=456
```

双引号支持含空格参数和空参数 `""`，参数中的双引号写作 `\"`。仅包含参数、没有标准输入的用例同样有效。
